# Analizador y Generador de Código para Pascal

Construcción de un compilador personalizado para el lenguaje Pascal desarrollado íntegramente en Java. 

## Tecnologías Utilizadas
*   **Lenguaje:** Java.
*   **Herramientas:** Git, GitHub (Integración y control de versiones colaborativo).

## Fases del Compilador Implementadas
*   **Analizador Léxico y Sintáctico:** Parseo de la gramática, identificación de tokens y manejo estructurado de errores de sintaxis.
*   **Analizador Semántico:** Gestión de la tabla de símbolos y validación de tipos y reglas de alcance.
*   **Generación de Código MEPA:** Traducción del árbol de sintaxis a código máquina de pila (MEPA) listo para su ejecución.
*   **Testing:** Diseño de casos de prueba exhaustivos (escenarios correctos e incorrectos) para validar el flujo completo y la captura de excepciones.
